What does crc32_z do?
AI
This is the zlib CRC-32 checksum core. It folds each input byte through a 256-entry table (crc_table) — byte-by-byte until 8-aligned, then 8 bytes per pass for speed.
• rsi = buffer, rdx = length, rdi = seed.
